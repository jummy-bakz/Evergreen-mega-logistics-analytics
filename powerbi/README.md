# Power BI Dashboard

This folder contains visual documentation of the Evergreen Mega-Logistics Power BI dashboard.

The report consists of four interactive pages:

1. Executive Operations & Financial Overview
2. Transit & Delivery Operations
3. Partner & Supplier Scorecard
4. Cost Optimization & Unit Economics

The dashboard provides visibility into shipment volumes, delivery performance, supplier reliability, logistics expenditure, route profitability, and operational improvement opportunities.
