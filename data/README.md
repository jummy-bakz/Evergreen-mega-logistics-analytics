# Dataset Documentation

This folder contains the synthetic dataset used for the Evergreen Mega-Logistics & Fleet Performance Framework.

The dataset contains 60,000 shipment records covering January 2024 to December 2025, alongside supporting dimension tables.

## Dataset Contents

* `fact_shipments.csv` – Shipment-level operational and financial transactions.
* `dim_date.csv` – Date dimension.
* `dim_locations.csv` – Origin and destination locations.
* `dim_carriers.csv` – Carrier information.
* `dim_suppliers.csv` – Supplier information.
* `dim_vehicles.csv` – Vehicle information.
* `data_dictionary.csv` – Dataset fields and descriptions.

## Data Usage

The dataset supports SQL analysis, Python data cleaning and validation, and Power BI dashboard development.

**Note:** This is a synthetic dataset created for educational and portfolio demonstration purposes. It does not represent actual company transactions.

## Dataset Coverage

* Shipment records: 60,000
* Period: January 2024 – December 2025
* Data format: CSV
