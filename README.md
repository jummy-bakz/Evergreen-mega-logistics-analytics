# Evergreen Mega-Logistics & Fleet Performance Framework

### End-to-End Logistics Analytics | MySQL · Python · Power BI

An end-to-end logistics analytics framework designed to evaluate fleet utilization, delivery performance, supplier reliability, and logistics cost efficiency through data engineering, analysis, and interactive business intelligence.

## Project Overview

The Evergreen Mega-Logistics Framework transforms shipment-level data into actionable operational and financial insights.

Using MySQL, Python (Pandas), and Power BI, the project demonstrates how logistics businesses can monitor delivery performance, identify operational bottlenecks, evaluate supplier reliability, and investigate cost optimization opportunities.

## Business Objectives

* Monitor shipment volume, fleet and route performance.
* Identify delivery delays and operational bottlenecks.
* Evaluate supplier SLA compliance and defect rates.
* Analyze logistics expenditure and route profitability.
* Highlight routes and operational areas requiring attention.
* Support data-driven logistics planning and decision-making.

## Project Dataset

| Attribute        | Details                      |
| ---------------- | ---------------------------- |
| Shipment records | 60,000                       |
| Data coverage    | January 2024 – December 2025 |
| Database tables  | 6                            |
| Dashboard pages  | 4                            |
| Primary tools    | MySQL, Python, Power BI      |

The project uses a generated portfolio dataset and does not contain confidential company records.

## Technology Stack

* **MySQL:** Relational database design, data validation, SQL analysis, aggregations, and business queries.
* **Python / Pandas:** Data cleaning, quality checks, exploratory analysis, anomaly investigation, and validation.
* **Power BI:** Data modeling, DAX measures, interactive dashboards, KPI monitoring, and operational reporting.

## Project Architecture

Master Logistics Dataset → MySQL → Python / Pandas → Power BI → Business Insights
