# Project Documentation

This folder contains the technical documentation and architecture of the Evergreen Mega-Logistics & Fleet Performance Framework.

## Data Workflow

The project follows an end-to-end analytics workflow:

**Master Logistics Dataset → MySQL → Python/Pandas → Power BI → Business Insights**

### MySQL

Relational database design, data storage, SQL validation, and operational analysis.

### Python/Pandas

Data cleaning, quality checks, exploratory analysis, and logistics performance investigation.

### Power BI

Data modeling, DAX measures, interactive dashboards, KPI monitoring, and business reporting.

### Business Insights

Identifying delivery bottlenecks, supplier performance issues, route-level cost differences, and opportunities for operational improvement.
